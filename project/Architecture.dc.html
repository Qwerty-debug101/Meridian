Deployment — Hostinger

PHASE 1Shared hosting
  • Laravel deployed to ~/domains/site; public_html → /public
  • React built with vite build, static assets served from /public
  • MySQL via hPanel; env secrets in .env (never committed)
  • Cron-driven schedule:run every minute for queues & email
  • Domain & DNS at Namecheap → A record to Hostinger; SSL via free Let's Encrypt
FUTUREVPS upgrade
  • Nginx + PHP-FPM 8.3; same codebase, no rewrites
  • Supervisor keeps queue:work running persistently
  • Redis for cache, sessions & queues (swap drivers in .env)
  • Object storage / CDN for product images as catalog grows
  • Optional: read replica when query volume demands it
Caveat: shared hosting has no persistent worker process — background email & queues rely on the cron scheduler, which is fine at low volume. Plan the VPS jump once you exceed ~50 orders/day or want sub-minute email delivery.
